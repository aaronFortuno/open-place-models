# Torre Glòries · r1

An original simplified solid model of the tower formerly known as Torre Agbar. The printable geometry preserves the oriented ovoid plan and the transition from the walls to the pointed dome. It represents the building envelope as a single solid at geographic scale. Authorship of the model is credited to Open Place Models contributors.

The footprint and ground-level anchor derive from OpenStreetMap way 44213122, version 43. The anchor is the centroid of that footprint. The model uses the mapped outline at ground level, the published overall height of 144.4 m, and an original smooth taper guided by the structural description of the outer wall and dome. The curve is an approximation for small-scale prints.
